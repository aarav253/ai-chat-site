# AI Assistant UI

A single-page, vanilla HTML/CSS/JS front-end mockup for a chat interface — sidebar with saved chats, a message thread, and an input bar styled after modern AI chat apps.

## What this is

A UI prototype, not a wired-up app. The send button appends messages to the thread locally, but isn't connected to a real model yet.

## Tech

Plain HTML, CSS, and JavaScript — no framework, no dependencies.

## Possible next steps

- Wire the input up to an actual model API to generate real responses
- Persist chat history
- Make the sidebar chats functional
